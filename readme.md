## System Requirements for Lens Studio 5.6.1
- **Operating System:** Windows 10 (64-bit) or macOS 11 (Big Sur) and above
- **Processor:** Intel Core i5 (7th Gen and above) or AMD Ryzen 5 equivalent
- **Memory:** 8 GB RAM (16 GB recommended)
- **Graphics:** NVIDIA GeForce GTX 970 / AMD Radeon RX 570 or better
- **Storage:** At least 2 GB of available disk space
- **Additional:** Requires an internet connection for installation and updates
